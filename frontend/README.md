# iAudit Frontend

React + TypeScript + Vite client for the iAudit audit management system.

## Stack

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS

## Local development

Requires Node.js and npm.

```sh
# From the frontend directory
npm install
npm run dev
```

The Vite dev server runs on port 8080 and proxies `/api` to the backend at `http://127.0.0.1:3001`.

## Build

```sh
npm run build
npm run preview
```
